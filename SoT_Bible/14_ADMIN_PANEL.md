## 1. Общая концепция

Панель администратора — **встроенный модуль** основного веб-приложения (TMA), доступный по скрытому URL-параметру (`?superadmin=true`) или через специальную кнопку в профиле после проверки роли администратора (или ввода PIN-кода). 

**Доступ:** Вход через основное приложение → проверка прав / PIN-кода → отображение интерфейса поверх основного приложения (Z-index).

**Роли:**
| Роль | Возможности |
|---|---|
| **Super Admin** | Все функции, включая управление ролями |
| **Moderator** | Отзывы, жалобы, верификация |
| **Support** | Чаты, апелляции, ответы пользователям |
| **Finance** | Транзакции, выплаты, партнёры |

### Действие при выдаче VIP статуса

Синяя галочка ✅ выдается вручную (или автоматически) после того, как провайдер приобрел **VIP статус**. Вкладка верификации используется для ручной проверки документов, если провайдер купил VIP.

```sql
-- При нажатии ✅ Верифицировать (Подтверждение VIP):
UPDATE business_profiles
SET verified = TRUE,
    verified_at = NOW(),
    verified_by_admin_id = 'admin_uuid',
    sub_plan = 'verified_partner',
    sub_expires_at = NOW() + INTERVAL '30 days'
WHERE user_id = 'provider_uuid';
```

**После верификации:**
- Провайдеру приходит Push в Telegram: «✅ Ваш аккаунт верифицирован! Статус Verified Partner активен»
- Появляется синяя галочка ✅ на бизнес-карточке и офферах

## 14. DB: Дополнительные таблицы для Admin Panel

```sql
-- Роли администраторов
CREATE TABLE admin_users (
    id          UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    telegram_id BIGINT UNIQUE NOT NULL,
    username    VARCHAR(64),
    role        VARCHAR(32) DEFAULT 'support',  -- super_admin | moderator | support | finance
    is_active   BOOLEAN DEFAULT TRUE,
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Лог действий администраторов
CREATE TABLE admin_audit_log (
    id          UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    admin_id    UUID REFERENCES admin_users(id),
    action      VARCHAR(128) NOT NULL,     -- 'verify_provider', 'hide_review', etc.
    target_type VARCHAR(64),               -- 'user', 'review', 'deal', etc.
    target_id   UUID,
    details     JSONB DEFAULT '{}',
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Рассылки
CREATE TABLE broadcasts (
    id          UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    admin_id    UUID REFERENCES admin_users(id),
    target      VARCHAR(32),               -- 'all' | 'clients' | 'providers'
    hub_filter  VARCHAR(64),
    lang_filter VARCHAR(8),
    message     TEXT NOT NULL,
    buttons     JSONB DEFAULT '[]',
    status      VARCHAR(16) DEFAULT 'draft', -- draft | sent | scheduled
    sent_at     TIMESTAMP WITH TIME ZONE,
    recipients_count INT DEFAULT 0,
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```
